# Corti Hearing Clinic

Official website for **Corti Hearing Clinic** — hearing tests, hearing aids, and therapy in Bengaluru (Frazer Town, Vijayanagar) and Tumkur.

Live brand site: [corti.in](https://corti.in)

This is a modern recreation of the original clinic website: same copy, photography, logo, and gold-and-black identity, with clearer type, working contact (WhatsApp), maps, SEO, and a mobile-first layout.

## Local development

```bash
npm install
npm run dev
```

Then open the printed local URL. Production build:

```bash
npm run build
```

Deploy on Vercel, Netlify, or any host that runs a Node/Vite app. All clinic photos and the logo live in `public/images/`.
